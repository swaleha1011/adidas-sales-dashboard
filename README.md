# 📊 Adidas US Retail Sales Dashboard

Interactive Power BI dashboard analyzing 9,652 retail transactions from Adidas US sales (2020-2021).

## 📈 Key Metrics

| Metric | Value |
|--------|-------|
| Total Sales | $899.9M |
| Total Profit | $332.1M |
| Profit Margin | 36.9% |
| Units Sold | 2.5M |
| Top Region | West ($269.9M) |
| Top Product | Men's Street Footwear ($83M) |
| Top Channel | In-store (39.6%) |

## 🔍 Key Insights

- **Regional Performance:** West region leads with $269.9M (30% of total sales)
- **Product Category:** Footwear dominates with $356.6M in sales
- **Sales Channel:** In-store is the top channel at 39.6%, followed by Outlet (32.9%) and Online (27.5%)
- **Profitability:** Overall profit margin is 36.9%, with South region showing highest margin (42.3%)

## 🛠️ Tools & Skills Used

- **Power BI Desktop** — Dashboard development
- **Power Query** — Data cleaning and transformation
- **DAX** — Custom measures and calculated columns
- **Data Modeling** — Star schema with Date dimension
- **Excel** — Source data management

## 🎨 Dashboard Features

- 4 KPI cards with currency and percentage formatting
- Time-series line chart for sales trends
- Top products horizontal bar chart
- Regional performance matrix
- Sales channel donut chart
- Profit vs Units scatter plot
- Interactive filter panel with slicers (Year, Region, Category, Sales Method)
- Reset filters button
